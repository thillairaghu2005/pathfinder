## About Pathfinders

**Pathfinders – The Guide** is a holistic academic coaching and mentoring academy dedicated to helping students and working professionals unlock their potential. From Higher Secondary school through undergraduate and postgraduate study (MBA, M.Phil) to PhD research, Pathfinders delivers personalized, subject-expert guidance that extends beyond the classroom.

Complementing individual mentoring, Pathfinders partners with colleges and enterprise organizations to conduct structured skill-development workshops, campus placement training, and corporate leadership programs.

---

## Core Offerings

### 1. Academic Coaching (Higher Secondary to PhD)
- **Commerce & Management (Flagship):** Accountancy, Finance, Business Studies, Economics, Marketing, HR, Operations, MBA case studies, and coursework.
- **Engineering:** Core and applied engineering disciplines, structured problem-solving, laboratory project guidance, and technical assessments.
- **Sciences & Mathematics:** Fundamentals-first coaching from Higher Secondary to postgraduate levels.
- **Arts, Humanities & Research:** Dedicated dissertation, thesis, literature review, research methodology, and data analysis support for postgraduate and doctoral scholars.

### 2. Corporate & College Training
- **Corporate Programs & Workshops:** Communication, leadership, business etiquette, negotiation, feedback systems, and workplace stress management.
- **College Workshops:** Group discussions, personal interview preparation, resume clinics, and personality development.
- **Campus Placement Training:** Quantitative aptitude, analytical reasoning, mock interviews, and research methodology orientation.

### 3. Flexible Learning Modes
- **Formats:** Focused hourly consultation sessions and comprehensive monthly programs.
- **Delivery:** In-person sessions at **Chennai** and **Trichy** centres, or interactive **Online Coaching** accessible across India and globally.

## Getting Started

### Prerequisites

- **Node.js**: v18.0.0 or higher
- **npm** or **pnpm** / **yarn**

### Quick Start

```bash
# 1. Clone the repository
git clone https://github.com/thillairaghu2005/pathfinder.git
cd pathfinder

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev
```

The application will be accessible at `http://localhost:5173`.

### Available Scripts

- `npm run dev` – Launch Vite local development server with HMR.
- `npm run build` – Run TypeScript type-checking and create optimized production build in `/dist`.
- `npm run preview` – Locally preview the generated production build.
